# Download e instalação

1. Baixe a ISO inteira (um arquivo só) da edição certa para o seu computador:
   - **Fênix** (4 GB de RAM ou mais, 2,4 GB): **[https://gofile.io/d/IMrf2TPM](https://gofile.io/d/IMrf2TPM)**
   - **Fênix Lite** (computadores antigos, processador de 64 bits, 1,7 GB): **[https://gofile.io/d/WWvc6XnI](https://gofile.io/d/WWvc6XnI)**
   - **Fênix Lite 32** (computadores antigos de 32 bits, 1,8 GB): **[https://gofile.io/d/42gKQkbY](https://gofile.io/d/42gKQkbY)**
2. (Opcional) confira o SHA-256 — Fênix: `030d7025131a75331b7b2fa3e2fceab883cfc12542b8c13546e91188855ef1db` · Fênix Lite: `01b82a740d0ff6a25a27d662485e238becf2b482cfd973ceb863f3b74ecba396` · Fênix Lite 32: `f9cb5733e8e90d8c33ccda12eac50e96a2dac028bbe328d34a99a5fd5b0ec8ee`
   - Windows (PowerShell): `Get-FileHash konaro-os-fenix-0.1.1-amd64.iso -Algorithm SHA256`
   - Linux: `sha256sum konaro-os-fenix-0.1.1-amd64.iso`
3. **Máquina virtual (recomendado)**: VirtualBox → Linux / Debian 64-bit, 4 GB+ de RAM, 2 CPUs, disco de 30 GB, vídeo VMSVGA com 128 MB.
5. **Pendrive**: Ventoy, Rufus (modo DD) ou balenaEtcher. ⚠️ Escolher o disco errado apaga os dados dele. O Secure Boot pode ficar ligado.

Sessão live: usuário `konaro`, senha `live`.
