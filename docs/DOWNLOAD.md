# Download e instalação

1. Baixe a ISO inteira (um arquivo só, 2,7 GB): **[https://gofile.io/d/xAf862BJ](https://gofile.io/d/xAf862BJ)**
2. (Opcional) confira o SHA-256 — tem que dar `6f03eddc48efe9e827a46808f67d25f2982aa39d7506d24392ac5b8b25e636f6`:
   - Windows (PowerShell): `Get-FileHash konaro-os-0.1.0-dev6-amd64.iso -Algorithm SHA256`
   - Linux: `sha256sum konaro-os-0.1.0-dev6-amd64.iso`
3. **Máquina virtual (recomendado)**: VirtualBox → Linux / Debian 64-bit, 4 GB+ de RAM, 2 CPUs, disco de 30 GB, vídeo VMSVGA com 128 MB.
5. **Pendrive**: Ventoy, Rufus (modo DD) ou balenaEtcher. ⚠️ Escolher o disco errado apaga os dados dele. O Secure Boot pode ficar ligado.

Sessão live: usuário `konaro`, senha `live`.
