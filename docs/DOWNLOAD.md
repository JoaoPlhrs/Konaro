# Download e instalação

1. Baixe a ISO inteira (um arquivo só, 2,8 GB): **[https://gofile.io/d/1wTmBC8V](https://gofile.io/d/1wTmBC8V)**
2. (Opcional) confira o SHA-256 — tem que dar `5da6c147720f9e4d2272492014ec0e526f1e12cb4ae67c4d128b7e59e7655206`:
   - Windows (PowerShell): `Get-FileHash konaro-os-0.1.0-dev8-amd64.iso -Algorithm SHA256`
   - Linux: `sha256sum konaro-os-0.1.0-dev8-amd64.iso`
3. **Máquina virtual (recomendado)**: VirtualBox → Linux / Debian 64-bit, 4 GB+ de RAM, 2 CPUs, disco de 30 GB, vídeo VMSVGA com 128 MB.
5. **Pendrive**: Ventoy, Rufus (modo DD) ou balenaEtcher. ⚠️ Escolher o disco errado apaga os dados dele. O Secure Boot pode ficar ligado.

Sessão live: usuário `konaro`, senha `live`.
