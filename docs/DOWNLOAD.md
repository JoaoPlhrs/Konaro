# Download e instalação

1. Baixe a ISO inteira (um arquivo só, 4,1 GB): **[https://gofile.io/d/IuvlFwTS](https://gofile.io/d/IuvlFwTS)**
2. (Opcional) confira o SHA-256 — tem que dar `f3b7559b656f749a0097962b444a06619799f9de65910c2aea6248b398f97fe9`:
   - Windows (PowerShell): `Get-FileHash konaro-os-0.1.0-dev1-build5-amd64.iso -Algorithm SHA256`
   - Linux: `sha256sum konaro-os-0.1.0-dev1-build5-amd64.iso`
3. **Máquina virtual (recomendado)**: VirtualBox → Linux / Debian 64-bit, 4 GB+ de RAM, 2 CPUs, disco de 30 GB, vídeo VMSVGA com 128 MB.
5. **Pendrive**: Ventoy, Rufus (modo DD) ou balenaEtcher. ⚠️ Escolher o disco errado apaga os dados dele. O Secure Boot pode ficar ligado.

Sessão live: usuário `konaro`, senha `live`.
