# Download e instalação

1. Baixe a ISO inteira (um arquivo só) da edição certa para o seu computador:
   - **Fênix** (4 GB de RAM ou mais, 2,4 GB): **[https://gofile.io/d/mfNalg4T](https://gofile.io/d/mfNalg4T)**
   - **Fênix Lite** (computadores antigos, processador de 64 bits, 1,8 GB): **[https://gofile.io/d/vGj27CVP](https://gofile.io/d/vGj27CVP)**
   - **Fênix Lite 32** (computadores antigos de 32 bits, 1,8 GB): **[https://gofile.io/d/fTNK6oQ8](https://gofile.io/d/fTNK6oQ8)**
2. (Opcional) confira o SHA-256 — Fênix: `018b3422aa6af2c1a5a8ca4d36371b014f2fc73e1b0a2f0a901fb3585bc3e1bd` · Fênix Lite: `504b09255b95d5960e28d19b2aa5aa0b7024b05dc75f4e7ca0a06af2145e52ca` · Fênix Lite 32: `cbf569a0193583cfc9ed264265cc54ffeedfca5803e0a5364a302f4b54ae3cd7`
   - Windows (PowerShell): `Get-FileHash konaro-os-fenix-0.1.0-amd64.iso -Algorithm SHA256`
   - Linux: `sha256sum konaro-os-fenix-0.1.0-amd64.iso`
3. **Máquina virtual (recomendado)**: VirtualBox → Linux / Debian 64-bit, 4 GB+ de RAM, 2 CPUs, disco de 30 GB, vídeo VMSVGA com 128 MB.
5. **Pendrive**: Ventoy, Rufus (modo DD) ou balenaEtcher. ⚠️ Escolher o disco errado apaga os dados dele. O Secure Boot pode ficar ligado.

Sessão live: usuário `konaro`, senha `live`.
