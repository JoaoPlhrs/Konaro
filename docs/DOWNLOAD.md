# Download e instalação

1. Baixe a ISO inteira (um arquivo só, 2,7 GB): **[https://gofile.io/d/O996OXic](https://gofile.io/d/O996OXic)**
2. (Opcional) confira o SHA-256 — tem que dar `3e03e19c9c534cfa1fa591833c99ebff36aeadbb51c49062bbe447a5c39b3974`:
   - Windows (PowerShell): `Get-FileHash konaro-os-0.1.0-dev7-amd64.iso -Algorithm SHA256`
   - Linux: `sha256sum konaro-os-0.1.0-dev7-amd64.iso`
3. **Máquina virtual (recomendado)**: VirtualBox → Linux / Debian 64-bit, 4 GB+ de RAM, 2 CPUs, disco de 30 GB, vídeo VMSVGA com 128 MB.
5. **Pendrive**: Ventoy, Rufus (modo DD) ou balenaEtcher. ⚠️ Escolher o disco errado apaga os dados dele. O Secure Boot pode ficar ligado.

Sessão live: usuário `konaro`, senha `live`.
